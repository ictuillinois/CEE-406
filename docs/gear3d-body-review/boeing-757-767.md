# Boeing 757 and 767 expansion

Five dedicated airframes replace the old 737/787 substitutes for these families.
757-300, 767-200 and 767-300ER are new catalog entries; 757-200 and 767-400ER
keep their existing IDs with reviewed geometry. The library has 28 named aircraft.
Generic FAA gear schematics remain separate.

## Primary references

- [Boeing 757 ACAP D6-58327 Rev H, December 2024](https://www.boeing.com/content/dam/boeing/v2/airports/acaps/757_Rev_H.pdf):
  sections 2.1.1 / 2.1.4 (weights), 2.2.1 / 2.2.2 (dimensions),
  2.3.1 / 2.3.2 (clearances), 7.2 (footprints). PDF pages 16, 19–23, 117.
- [Boeing 767 ACAP D6-58328 Rev K, December 2024](https://www.boeing.com/content/dam/boeing/v2/airports/acaps/767_REV_K.pdf):
  sections 2.1.1 / 2.1.4 / 2.1.6, 2.2.1 / 2.2.2 / 2.2.4,
  2.3.1 / 2.3.2 / 2.3.4, 7.2.1–7.2.3. PDF pages 22, 25, 27–29, 31–33, 35, 193–195.

Dimensioned footprint and general-arrangement drawings were visually reviewed;
the PDFs' text extraction omits many drawing labels. The manuals stay at Boeing;
this repository distributes transcribed dimensions and citations.

## Selected configurations

Weights are pounds, dimensions below are inches as printed in the drawings,
and pressure is psi. The generator converts inches to mm using 25.4 exactly.

| Aircraft | MTOW / taxi | Wheelbase | Track | Nose pitch | Main dual / tandem pitch | Main / nose pressure |
| --- | --- | ---: | ---: | ---: | --- | --- |
| 757-200 | 255500 / 256000 | 720 | 288 | 24 | 34 / 45 | 183 / 155 |
| 757-300 | 270000 / 271000 | 880 | 288 | 24 | 34 / 45 | 200 / 136 |
| 767-200 | 315000 / 317000 | 775 | 366 | 25 | 45 / 56 | 165 / 146 |
| 767-300ER | 412000 / 413000 | 896 | 366 | 25 | 45 / 56 | 200 / 172 |
| 767-400ER | 450000 / 451000 | 1030 | 366 | 25 | 45.8 / 54 | 213 / 170 |

The 757-200's 255500 lb option is limited to airport altitudes below 1500 ft
by table 2.1.1 footnote 1. The 767-300ER's 413000 lb taxi column is paired
with its 412000 lb takeoff configuration; the non-ER table's different weight
columns are not mixed into this entry. Main tires are H40x14.5-19 for both
757s, H46x18.0-20 for the 767-200/-300ER, and 50x20.0R22 for the -400ER.
Nose tires are H31x13.0-12 and H37x14.0-15 respectively.

The old 757 nose pitch (508 mm) becomes the documented 609.6 mm;
the old 767-400ER nose pitch (546 mm) becomes 635 mm. Track now comes directly
from the drawings (7315.2 / 9296.4 mm), replacing rounded outer-width
derivations. The -400ER wheelbase becomes 26162 mm and dual pitch 1163.32 mm.
All entries keep a declared 95% main-gear design load assumption and separate
takeoff/taxi weights. Imported older projects keep their saved dimensions;
these corrections apply when selecting the catalog entry.

## Body preparation and placement

The [Flightradar24 collection](https://github.com/Flightradar24/fr24-3d-models)
supplies distinct b752, b753, b762, b763 and b764 meshes, pinned to commit
`dd53267690c6a4ecbb290a3acf0284333a5d68a9`. FlightGear/FGMEMBERS authors,
GPLv2 license, original GLBs, editable Blender files and upstream source ZIPs
are preserved in the [source archives and manifest](../../public/gear3d/bodies/sources/manifest.json).
[Credits](../../public/gear3d/bodies/CREDITS.md) identify each upstream project.

Preparation converts glTF 1 to glTF 2, removes source gear and textures,
bakes transforms and combines surfaces into one draw call. No triangle
simplification or variant stretching is applied.

| Body | Triangles | Bytes |
| --- | ---: | ---: |
| B757-200 | 33411 | 725904 |
| B757-300 | 35320 | 789668 |
| B767-200 | 12647 | 293944 |
| B767-300 | 13350 | 322168 |
| B767-400 | 13318 | 353192 |

Each body loads only when selected. Source archives are never fetched by the
renderer. The detailed 757s have a separate 40000-triangle test budget;
the other detailed aircraft retain their 30000-triangle budget.

Overall lengths use the plan-view labels: 1863, 2143, 1910, 2163 and 2416 in.
The nose overhang is 232 in for both 757s and 179 in for all three 767s.
The rigid, zero-pitch visual attitude uses the midpoint of the published
tail-height range: 13.615, 13.600, 15.865, 15.710 and 16.845 m respectively.
Those midpoints are explicit visual assumptions, not simulated loading states.
Vertical intersections at gear stations set illustrative strut attachment
heights slightly inside the body surface; wheel footprints are unchanged by
this visual calibration.

Meshes are illustrative rather than manufacturer CAD. The 757-200 retains
source winglets, while the cited general drawing shows the basic wing.
At the published overall lengths, the prepared spans are approximately
39.164, 37.875, 44.605, 46.088 and 52.033 m. In particular, the 767-200 source
span is about 6% smaller than Boeing's 47.574 m drawing. Source proportions
are retained and these differences are not used for engineering dimensions.
The b763 mesh represents the 767-300ER; engine-option details are illustrative.
Bodies remain excluded from engineering exports.

## Reproduction and validation

1. Extract `models/<model>.glb` from each source archive to a working directory
   as `fr24-<model>.glb`.
2. Run `scripts/convert-gear3d-fr24.mjs` with gltf-pipeline 4.3.1.
3. Run `node scripts/build-gear3d-bodies.mjs <source-dir> B757-200 B757-300 B767-200 B767-300 B767-400`.
4. Run `node scripts/build-gear3d-boeing.mjs` to reproduce the catalog.
5. Run `node --test src/components/react/gear3d/*.test.mjs`, `npm run build`,
   and `scripts/check-gear3d-aircraft.mjs <preview-url>`.

Fifteen side/top/perspective pixel comparisons pass with zero changed pixels.
They validate exported geometry against the prepared source, not against
manufacturer CAD. Regression checks cover unique catalog IDs, all ten wheel
locations per aircraft, load conservation, weight/pressure selection, exact
variant-to-body mapping, finite geometry and ground clearance.

Production browser checks pass for all 23 reviewed entries plus the existing
777 selection, with zero page errors. The longest new variants fit Quad views
at 320, 768 and 1024 px without horizontal overflow. The 33-page production
build passes. Final app views are saved alongside this review as
`app-b757-200.png`, `app-b757-300.png`, `app-b767-200.png`,
`app-b767-300er.png` and `app-b767-400er.png`.
